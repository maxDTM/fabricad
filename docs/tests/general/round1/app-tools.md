# APP-TOOLS round 1 (QA, display :33, real X input only)

Screenshots: docs/tests/general/round1/app-tools/

## Issues
- APP-TOOLS-1 (high, functional): Parameters dialog, renaming a parameter to an existing name silently overwrites/merges the other parameter (q renamed to "width" -> width becomes 5 in, q row gone, no warning). Ctrl+Z restores. Shots: 113.png, params_after_rename.png.
- APP-TOOLS-2 (high, functional): Parameters dialog, renaming a parameter to an invalid name ("my var") deletes the parameter instead of rejecting the edit (z row vanished). Shots: 114.png.
- APP-TOOLS-3 (medium, functional): Invalid expressions are silently coerced in feature dialogs: Extrude distance "5 foo" -> 5 mm, taper "1/0" -> 1 deg; field just gets a red border and OK stays enabled and commits. Shots: 130.png, 131.png.
- APP-TOOLS-4 (medium, functional): No Preferences dialog anywhere (TOOLS tab has only Export; no Parameters/Scripts/Preferences per ux.md; status-bar "mm" label does nothing; S search "pref" finds nothing). Units/preferences cannot be tested. Shot: 118.png, 120.png.
- APP-TOOLS-5 (medium, functional): Appearance (A) shortcut does nothing, and "Appearance" is not in the MODIFY menu nor found by S search ("appear"); only reachable via the browser body context menu. Pressing A with browser focus starts a type-ahead/inline rename editor on the root node instead. Shots: 148.png, 150.png, 152.png.
- APP-TOOLS-6 (low, functional): ":" key focuses the command box but also inserts ":" into it, so ":FIT" runs "Unknown command: :FIT". Shot: cmdbox.png.
- APP-TOOLS-7 (low, functional): Command line lacks documented commands: UNITS and ZOOM (E/W) give "Unknown command". Shots: 50.png, 101.png.
- APP-TOOLS-8 (low, functional): S command search ranking/matching is noisy: "pref" lists Edit Dimension (disabled), Offset Face, Insert STEP/STL...; "meas" lists Baseline Dimension, Move, Offset Face, Mirror; disabled (greyed) commands rank above enabled ones. "appear" lists unrelated Perpendicular/Add Revision. Shot: search.png.
- APP-TOOLS-9 (low, visual): Interference dialog: results table Volume column truncated (needs horizontal scroll); selecting a row only highlights the two bodies, the intersection volume is not shown. Shots: 116.png, 117.png.
- APP-TOOLS-10 (low, functional): Ctrl+Z while the cmd> box has focus recalls the previous command text (QLineEdit undo) instead of undoing the model; later typing is appended to the ghost text ("LIST featuresLIST features"). Shots: 133.png, 144.png.
- APP-TOOLS-11 (low, functional): Timeline drag of a feature icon (the NewComponent Body2) to an earlier position is accepted without validation; features become "Stale / rolled back" and order is changed (Body2 before the Extrude that produces it). Shots: 141.png, 142.png.
