## Startup cost

The IGES / OBJ / glTF toolkits (TKDEIGES, TKRWMesh, TKDEOBJ, TKDEGLTF) live in the plugin
`libfabricad_interop.so` (`src/interop`), loaded with QLibrary on the first IGES / OBJ / glTF use;
`ldd fabricad` lists none of them. Linking them into the executable directly cost about 5 ms
(89 → 95 ms) per start. Startup of `fabricad --script empty.fcs --offscreen`, 15 runs each,
alternating with main: main 145.3 ms, pf/p3 146.3 ms median (same within noise). 3MF and the
face DXF need no new library.
