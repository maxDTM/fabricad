Branch `ui/viewport`. Plan: `docs/plans/ui-redesign.md` 4.5, 5.3, 6.3, 7.2-7.4, 8.2 and the phase 4 row of section 10.

## Built
| Piece | File | Notes |
|---|---|---|
| `ViewerPalette` | `src/viewer/ViewerPalette.*` | Every viewport colour from the tokens (background, grid, lights, body default/edges/hidden-line fill, selection and preselection with the 1 px halo, preview roles live/cut/new body with fill, edge, halo and glow, manipulators, axis colours, sketch styles, profile tints, construction/origin, ViewCube, overlays, value chip). `preview(PreviewStyle)` resolves `core::ColorRole`; `manipulatorColor()` gives gold handles, axis colours for the triad, `live.bright` on hover/drag. |
| `core::ColorRole` | `src/core/ViewerContext.h` | Small core addition (section 9 request): `PreviewStyle::role`; the presets set Live / Cut / NewBody / SketchFree / Inference. RGBA stays the headless fallback. |
| No colour literals in `src/viewer` | `ViewerWidget.cpp`, `SceneModel.*`, `occt/OcctView.cpp` | Lights, material, triedron (removed: the dial shows the axes), origin labels, selection outline, value label, scene style colours (`styleColor(style, palette)`), default body colour (`bodyColor`). Allow-list lines for the viewer are gone; `ValueInputOverlay.cpp` too. |
| Halo rule, two-tone previews | `ViewerWidget.cpp`, `PrimitivePrs.*` | Selected / hovered faces: token tint (no opaque wash, p1 L8) + edge outline over a 1 px-each-side halo. Shape previews: fill + edge + halo + 35 % glow (live). Line previews get the halo for accent roles. |
| Manipulators | `ManipulatorPrs.*` | Token colours, ink outline (inverted hull), glow shell on the hovered/dragged handle, diamond at the base of a distance arrow. |
| Hex orientation dial | `src/viewer/ViewportOverlays.*` `#OrientationDial` | Plate, 15 deg tick ring (45 major), gold azimuth mark, projected X/Y/Z tips (filled with letters / hollow negative), AZ/EL readout, ISO TOP FRONT RIGHT. Tip click = that view (again = opposite), vertex = nearest iso, ring drag = azimuth, inside drag = orbit, wheel = elevation 15 deg, keys (Tab focus, arrows, Home), right-click = the ViewCube menu. Math in `ViewerMath` (`azimuthElevation`, `azElOrientation`, `projectAxis`, `isoCornerNear`, ...). |
| ViewCube option | `ViewerWidget::setOrientationWidget` | `ui/orientation` switches live (`MainWindow::applyViewportSettings`). Cube recoloured from `vp.cube.face` / `vp.cube.edge` (new tokens; edges and corners darker, so the light cube has an outline: p0/p1 M1). Readout + view buttons sit under it. Corner zones are resolved in screen space (`cubeCornerHit`, 13 px), so iso views are reachable from face-on views (VIEWER-7). |
| Breadcrumb, selection filter | `#Breadcrumb`, `#SelectionFilterBar` | Document > component (or the single body) + gold chip (`EDITING <name>` while a feature or sketch is edited, else the command name). Filter segments BODIES FACES EDGES SKETCH PROFILES drive `setSelectionPriority` (new `SelectionPriority::Sketch`); segments the tool cannot pick hide; a tool restricted to one segment lights it. Wraps to two rows under 900 px. |
| View-tool column | `src/app/NavBar.*` (`#NavBar`, property `overlay=ViewToolColumn`) | Replaces the bottom bar: fit, orbit, pan, zoom, display (visual style, camera, visibility, grid and navigation sub-menus), views. Right edge below the dial; beside the dial when the viewport is too short. |
| Readout, scale bar | `#CoordReadout`, `#ScaleBar` | X/Y/Z of the pick point (else the sketch plane, else the ground plane) with axis ticks and unit cell; 1-2-5 ruler from `pixelSize()` at the view centre, document units. |
| Overlay registration | `ViewerWidget::addOverlayRegions`, `MainWindow::layoutOverlays`, `CommandCard::buildLayout` | All overlays are fixed regions of the one `OverlayLayout`; the card keeps 56 px from the dial (v6 box) and clears the column, top row and bottom readouts. The GL view is lowered under every overlay child; overlays never raise over the card. |
| Value box restyle | `src/sketch/ValueInputOverlay.cpp`, `app.qss.tmpl` | Inline QSS removed: `#fcValueBox` with a caption tag `#fcValueTag` above `#fcValueField`, properties `state` (idle/active/error) and `locked`. Dark field in dark (p1 L8), gold 2 px frame while active. |
| SK-12 | `SceneModel.cpp` | Closed profiles of visible finished sketches show as a light, unlit, non-pickable tint (`SceneStyle::ProfileShade`); tools picking profiles still get the pickable `Profile` style. |
