Not vendored (reference reading only, re-implemented from the recipes in `docs/research/`):
FreeCAD TechDraw (`GeometryObject.cpp`, `DrawViewSection.cpp`) for HLR projection, section
cuts and the DXF R12 layout in `src/drawing`; FreeCAD Assembly for the joint model in
`src/assembly`. The sketch inference, part features other than the hole profile, and the
whole app shell are original code.

Reference copies live outside the repository in `../fabricad-ref/` and are documented in
`docs/research/freecad-occt.md`.

Round 2 (sketch curves / drawing annotations): no third-party code was copied. The ISO 286
limits-and-fits values in `src/drawing/Tolerance.cpp` are published engineering constants
(ISO 286-1 table 1, ISO 286-2 fundamental deviations); the B-spline evaluation and global
interpolation in `src/sketch/SketchCurves.cpp` are re-implemented from the algorithms in
Piegl & Tiller, *The NURBS Book* (A2.2/A2.3, eq. 9.8); the ellipse / B-spline constraints use
the already vendored PlaneGCS.

Round 2 (icons, features, manipulators, tabs / scripting, value boxes): no third-party code was
copied. The icon set in `resources/icons/` is original artwork generated by
`resources/icons/generate_icons.py` (LGPL-2.1-or-later like the rest of the tree). The ISO 261
/ ISO 68-1 thread table and the ISO 273 clearance series in `src/part/ExtraUtils.cpp` are
published standard values; the manipulator math, selectors, script runner and dynamic-input
model are original code.
